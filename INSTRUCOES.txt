# 📋 Instruções de Atualização — Dashboard com Gráficos
# =====================================================

## Arquivos para ADICIONAR (novos):
  - css/dashboard.css      → Cole na pasta css/
  - js/modules/charts.js   → Cole na pasta js/modules/

## Arquivos para SUBSTITUIR (atualizados):
  - js/app.js              → Substitua o existente
  - js/modules/theme.js    → Substitua o existente

## Alteração no index.html:

### 1. Adicione o CSS do dashboard no <head> (após os outros CSS):
<link rel="stylesheet" href="css/dashboard.css">

### 2. Adicione o Chart.js CDN ANTES do firebase SDK:
<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.7/dist/chart.umd.min.js"></script>

### 3. Substitua o bloco do page-dashboard pelo novo HTML
   (o novo HTML está no arquivo index.html deste ZIP)

## Resumo das mudanças:
- 🎯 Radar Chart: Nichos de atuação (projetos vs clientes por segmento)
- 📊 Doughnut Chart: Status dos projetos (com total no centro)
- 🔥 Bar Chart: Distribuição por prioridade
- 🏆 Bar Chart: Top clientes por número de projetos
- 🌗 Charts se adaptam automaticamente ao tema claro/escuro
